# MVP Specification v0.1

Project: The Last Word War

## Goal

Build the smallest playable digital version of the game.

## Features

### Player Setup

- Enter player names
- Define turn order

### Gameplay

- Display current word
- Input sentence
- Extract last word automatically
- Move to next player

### Scoreboard

- Display player scores
- Add point for valid sentence
- Deduct point for invalid sentence

### Timer

- 60 second countdown
- Timeout detection

### Validation

Initial version:

- Human referee decides:
    - Valid
    - Invalid

AI validation will be added later.

## Out of Scope

Not included in v0.1:

- Login system
- Database
- Multiplayer networking
- AI referee
- Mobile application
- User accounts
- Tournaments

## Success Criteria

Two players can play a complete game in a browser.
