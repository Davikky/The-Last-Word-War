# Purpose

This document defines the long-term strategic direction of **The Last Word War™**.

Where the Project Philosophy defines why the project exists, this document defines how the project intends to realize that philosophy through software development, research, community growth, educational applications, and long-term stewardship.

Unlike the Project Philosophy, this strategy is expected to evolve as evidence is gathered through development, playtesting, research, and community engagement.

---

# Strategic Mission

The Last Word War™ seeks to become:

- a human-centered multiplayer interaction platform;
- an educational gaming framework;
- a research initiative advancing Computational Facilitation and Human-Centered Computing.

The project's strategic objective is to demonstrate that computation can strengthen meaningful Human ↔ Human interaction without replacing human judgment, creativity, negotiation, or responsibility.

---

# Strategic Vision

The project is built upon a simple strategic principle:

> **Computers coordinate interaction.**
>
> **Humans create meaning.**

The software exists to facilitate interaction rather than govern it.

Long-term development should continuously strengthen this distinction.

---

# Core Development Strategy

The project follows an evidence-driven development cycle.

> **Build → Test → Learn → Refine**

Every significant feature should be validated through observation before becoming a permanent part of the platform.

The project intentionally avoids:

- feature accumulation without validation;
- premature optimization;
- technology-driven development;
- unnecessary automation of human decision-making.

Evidence should guide expansion.

# Computational Strategy

The project formally adopts **Computational Facilitation** as its long-term computational strategy.

The software should coordinate gameplay by providing:

- multiplayer synchronization;
- room management;
- turn coordination;
- timeout enforcement;
- score tracking;
- sentence history;
- automatic last-word extraction;
- session persistence;
- multiplayer integrity.

The software intentionally avoids responsibility for:

- interpreting meaning;
- judging creativity;
- evaluating sentence quality;
- resolving disputes;
- determining player intent.

Human participants remain responsible for the interpretation and social culture of gameplay.

---

# Artificial Intelligence Strategy

Artificial intelligence is not part of gameplay.

Instead, AI supports the broader project through:

- software development;
- documentation;
- research;
- accessibility;
- educational resources;
- publication;
- design exploration.

A future optional **AI Gameplay Analysis** may provide post-game educational observations after a match has officially concluded.

This analytical service:

- never changes the official winner;
- never modifies the official scoreboard;
- never acts as a gameplay referee.

Gameplay belongs to humans.

Reflection may involve artificial intelligence.

# Feature Evaluation Framework

Before introducing a new feature, ask:

1. Does this strengthen Human ↔ Human interaction?
2. Does this support Computational Facilitation?
3. Does this preserve human responsibility?
4. Does this improve usability?
5. Does this encourage learning or creativity?
6. Is the feature supported by evidence?
7. Does the feature avoid unnecessary automation?

Features satisfying these principles should receive priority.
