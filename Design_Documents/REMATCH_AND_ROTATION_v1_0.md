Author: Victor A. Adeyemi

---

# Purpose

This document defines the official rematch and turn-order rotation system used in The Last Word War.

The objective is to eliminate long-term starting-player advantages while supporting repeated matches between the same participants.

---

# Quick Rematch

A Quick Rematch starts a new match while preserving the existing player roster.

The following are reset:

* Scores
* Sentence History
* Current Word
* Timer
* Winner
* Final Round State
* Sudden Death State
* Referee State

The following are preserved:

* Player Names
* Player Order
* Match History (future versions)

---

# Starter Rotation

The starting player rotates after each completed match.

---

## Example

Players:

1. Victor
2. Sarah
3. Ahmed
4. Grace

### Match 1

Starter:

Victor

Turn Order:

Victor → Sarah → Ahmed → Grace

---

### Match 2

Starter:

Sarah

Turn Order:

Sarah → Ahmed → Grace → Victor

---

### Match 3

Starter:

Ahmed

Turn Order:

Ahmed → Grace → Victor → Sarah

---

### Match 4

Starter:

Grace

Turn Order:

Grace → Victor → Sarah → Ahmed

---

### Match 5

Starter:

Victor

---

# Advantages

This system:

* Eliminates persistent first-player advantage.
* Supports tournament play.
* Encourages fairness.
* Works for any number of players.
* Integrates naturally with Quick Rematch.
