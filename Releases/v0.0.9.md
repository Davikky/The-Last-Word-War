# The Last Word War

## Release Notes – v0.0.9

Release Date: 2026-06-17

Tag: v0.0.9

---

# Overview

Version 0.0.9 completes the first implementation of the official victory-condition system.

This release introduces Sudden Death tie resolution and completes the progression:

Active Play → Final Round → Sudden Death → Game Over

---

# New Features

## Sudden Death Mode

When tied players remain after the Final Round:

* The game enters Sudden Death.
* Only tied players continue participating.
* Non-tied players remain visible in standings but are eliminated from contention.

---

## Win-by-Two Rule

Sudden Death continues until:

Leader Score − Second Place Score ≥ 2

The leading player is then declared the winner.

---

## Sudden Death Turn Restriction

Only players participating in Sudden Death receive turns.

Eliminated players are automatically skipped.

---

## Automatic Winner Determination

The game now automatically determines:

* Final Round winners
* Sudden Death winners

without requiring manual intervention.

---

# Architecture Improvements

The game engine now supports:

* SETUP

* SUDDEN_DEATH

This establishes the core state machine for future multiplayer implementations.
