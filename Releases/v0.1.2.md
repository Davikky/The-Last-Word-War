# The Last Word War™

# Release Notes: v0.1.2

**Release Date:** 2026-07-06

**Status:** Feature Complete Alpha

---

# Overview

Version v0.1.2 focuses on improving the maintainability, consistency, and gameplay responsiveness of The Last Word War™.

While no major gameplay systems were introduced, this release significantly improves the internal architecture through component extraction and centralized gameplay configuration, laying the foundation for the next phase of codebase refactoring.

---

# Gameplay Improvements

## Turn Timing

* Reduced the default turn duration from **60 seconds** to **30 seconds**.
* Improved gameplay pace and player engagement.
* Centralized turn timing configuration for easier future balancing.

---

# Architectural Improvements

## Component Refactoring

The first phase of UI component extraction has been completed.

New reusable components include:

* `SentenceHistoryPanel`
* `PlayerListPanel`

These extractions reduce the size and complexity of `App.jsx` while improving separation of concerns and code maintainability.

---

## Gameplay Configuration

Introduced a centralized gameplay configuration module:

```text
src/constants/gameConfig.js
```

The module currently centralizes:

* turn duration;
* initial countdown values.

This removes hard-coded gameplay constants from the application and simplifies future gameplay tuning.

---

# Codebase Quality Improvements

This release continues the long-term refactoring effort by:

* reducing UI coupling;
* improving component reusability;
* eliminating additional magic numbers;
* improving overall code organization.

No gameplay rules were changed apart from the reduced turn duration.

---

# Project Status

The Last Word War™ remains in the **Feature Complete Alpha** stage.

Development has now transitioned from feature implementation to codebase refinement, architectural cleanup, and preparation for broader external playtesting.

---

# Next Milestone

## Codebase Refactoring

The next refactoring phase will focus on extracting additional presentation components from `App.jsx`, including:

* Game Status Panel
* Room Setup Panel
* Lobby Panel
* Game Over Panel

The long-term objective is to transform `App.jsx` into a lightweight orchestration component supported by reusable UI components, services, and pure game logic.
